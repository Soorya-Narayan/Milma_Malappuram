About this dashboard

What this is

A web-based monitoring dashboard for the PPI AIME 8U 8-channel universal analog input module at the Milma Malappuram dairy facility. It polls the RTU over Modbus TCP/IP once per second, stores readings in a local database, and serves a live view, historical trends, a tabular history, and Excel export in the browser.

How to use it

  1. Live — the home page. Shows the eight channel tiles, their present value (PV) and alarm state (HiHi / Hi / Lo / LoLo) updated every second over a WebSocket. Tile colour means:
    • Black (OK) — reading is within limits.
    • Amber — at least one alarm bit is active.
    • Red — sensor fault (open, under-range, over-range, or read failure).
    • Grey / dashed — no data yet, or channel disabled in Settings.
  2. Trends — plot one or more channels over a time range. Pick a preset (Last 1h / 6h / 24h / 7d) or a custom range, and press Plot. Toggle individual series on/off with the check-boxes above the chart. Hover the chart to read exact values.
  3. History — pivoted table of raw readings, one column per enabled channel. Pick a range and press Search. Use Export .xlsx to download the exact same view as an Excel file. The download file name includes the selected time range.
  4. Settings — change the theme (dark / light), set how often readings are written to the database (Logging cycle), rename channels, turn off channels you aren't using (disabled channels are not logged, trended, or exported), and manage data retention.
  5. Data retention — use the red button in Settings to manually delete everything older than 6 months, or tick Auto-delete data older than 6 months to have it run automatically every night at 03:00 local time.

Status indicator

The small green dot in the top-right of the navigation bar means the browser is connected to the server over WebSocket and Live values are streaming. If it turns off or grey, Live tiles go stale and the browser will reconnect automatically.
